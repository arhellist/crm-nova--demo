# Delta: tasks — полные поля в UI

## ADDED Requirements

### Requirement: Список и карточка задачи показывают полный набор полей ТЗ

Система MUST отображать на экране «Мои задачи» (в каждой строке/карточке) и на странице
задачи следующие поля: название, описание, объект, исполнитель, статус, автор, дата
создания. Пустое описание SHALL показываться явной подписью, а не скрываться молча.

#### Scenario: happy path
- GIVEN задача с заполненными полями и известными именами участников
- WHEN пользователь открывает «Мои задачи» и карточку задачи
- THEN видны все семь полей с читаемыми подписями

#### Scenario: negative — пустое описание
- GIVEN у задачи `description` пустая строка
- WHEN открыта строка списка или карточка
- THEN вместо текста описания показана понятная заглушка («Описание не добавлено» / аналог)
