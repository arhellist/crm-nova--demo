## Токены (CSS variables — целевые имена)

Референс использует короткие имена; в приложении те же значения живут в `src/styles/tokens.css`
и пробрасываются в Tailwind `theme.extend`. Переименование — только по таблице соответствия,
значения не меняются.

```css
:root {
  /* поверхности */
  --bg-0: #070a12;
  --bg-1: #0b1020;
  --bg-2: #101830;
  --panel: rgba(18, 26, 48, 0.72);      /* стеклянная панель */
  --panel-solid: #121a30;
  --stroke: rgba(120, 160, 255, 0.16);
  --stroke-strong: rgba(120, 160, 255, 0.34);

  /* акценты */
  --cyan: #22d3ee;
  --violet: #8b5cf6;
  --magenta: #e879f9;
  --lime: #a3e635;
  --amber: #fbbf24;
  --rose: #fb7185;

  /* текст */
  --text: #e8eeff;
  --text-dim: #9aa8c9;
  --text-mute: #65729a;

  /* радиусы */
  --r-sm: 10px;
  --r-md: 16px;
  --r-lg: 24px;

  /* свечения (только для активных/статусных элементов) */
  --glow-cyan: 0 0 24px rgba(34, 211, 238, 0.35);
  --glow-violet: 0 0 28px rgba(139, 92, 246, 0.35);

  /* шрифты */
  --font: "Inter", "Segoe UI", system-ui, -apple-system, sans-serif;
  --mono: "JetBrains Mono", "SF Mono", ui-monospace, monospace;
}
```

| Токен референса | Роль в Tailwind | Использование |
|-----------------|-----------------|---------------|
| `--bg-0` | `colors.bg.0` | фон приложения |
| `--bg-1`, `--bg-2` | `colors.bg.1/2` | панели, вложенные блоки, hover |
| `--panel`, `--panel-solid` | `colors.panel` | карточки, модалки, верхняя навигация |
| `--stroke`, `--stroke-strong` | `borderColor.stroke` | границы, разделители, фокус |
| `--cyan` | `colors.cyan` | основное действие, «В работе» |
| `--violet` | `colors.violet` | вторичное действие, «На проверке» |
| `--amber` | `colors.amber` | «На доработке», предупреждения |
| `--lime` | `colors.lime` | «Принята», успех |
| `--rose` | `colors.rose` | ошибки, архивирование |
| `--magenta` | `colors.magenta` | акцент статистики, «Новая» |
| `--r-sm/md/lg` | `borderRadius` | бейджи/карточки/модалки |
| `--font`, `--mono` | `fontFamily.sans/mono` | текст и числовые/кодовые значения |

Шрифты подключаются локально через `@fontsource/inter` и `@fontsource/jetbrains-mono`;
внешних CDN нет (требование CSP §8.7).

## Типографика и сетка

- Базовая сетка 8 px; отступы иконок и контролов кратны 4.
- Заголовки: 28/22/18 px, вес 600–700, отрицательный трекинг на крупных размерах.
- Основной текст 14–15 px, `--text-dim` для второстепенного, `--text-mute` для метаданных.
- Числовые метрики и идентификаторы — `--mono`.
- Максимальная ширина контента 1280 px, боковые отступы 24 px (16 px на мобиле).
- Стеклянные панели: `background: var(--panel)`, `backdrop-filter: blur(14px)`,
  граница `--stroke`, радиус `--r-md`.
- Анимация `rise` (8–12 px вверх + fade, 180–240 мс) — единственная кастомная; всё остальное —
  стандартные transition 150 мс. `prefers-reduced-motion: reduce` отключает `rise`.

## Статусные бейджи (цвет + подпись, не только цвет)

| Статус | Подпись | Цвет | Токен |
|--------|---------|------|-------|
| `new` | Новая | магента | `--magenta` |
| `in_progress` | В работе | циан | `--cyan` |
| `on_review` | На проверке | фиолетовый | `--violet` |
| `rework` | На доработке | янтарный | `--amber` |
| `accepted` | Принята | лаймовый | `--lime` |

Бейдж всегда содержит текст; цвет — вспомогательный признак (WCAG 2.1 AA, §7 ТЗ).

## Компоненты-референсы из HTML

| Компонент | Как выглядит в HTML | Как переносить в UI |
|-----------|---------------------|---------------------|
| Кнопка primary | заливка `--cyan`, тёмный текст, радиус `--r-sm`, glow при hover | вариант `primary`; disabled — 40% прозрачности, без glow |
| Кнопка violet | заливка `--violet`, светлый текст | вариант `secondary` |
| Кнопка ghost | прозрачный фон, граница `--stroke` | вариант `ghost`; destructive — `--rose` |
| Карточка объекта | `glass`-панель: название, адрес, прогресс, счётчики статусов | `ObjectCard`; клик по всей карточке, ссылка внутри — клавиатурно доступна |
| Таблица задач | заголовок, строки с бейджем статуса, исполнителем, датой | `TaskTable`; на < 768 px — карточки (`TaskCard`) |
| Колонки «Моих задач» | 5 колонок по статусам со счётчиками | `StatusColumns`; на мобиле — вертикальный стек |
| Таймлайн истории | вертикальная линия, точки цвета статуса, актор и время | `HistoryTimeline`; первая точка — создание задачи |
| Статистика (4 плитки) | `stat glass` с акцентной подсветкой | `StatCard`, используется на `/objects` и `/reports` |
| Верхняя навигация | логотип, пункты, имя и роль пользователя, выход | `AppShell`; пункты скрываются по роли |
| Статусный степпер | `status-stack` — бейджи всех статусов | `StatusStack` в карточке задачи и в фильтрах |

## Чего в референсе нет и что нужно дорисовать по токенам

- Формы входа и шага MFA, тексты ошибок, блокировка кнопки при отправке.
- Модалки: возврат на доработку с обязательным комментарием, архивирование объекта и задачи.
- Состояния списков: скелетон, «пусто» с CTA, ошибка с «Повторить», «нет доступа» (404).
- Экран отчётов и индикатор актуальности (`lag_seconds`, `source: replica`).
- Адаптив 360/768/1440: таблица → карточки, навигация → компактное меню.
- Фокус-стили, `aria-*` подписи, контраст ≥ 4.5:1 (проверяется на этапе UI-D).

## Запреты для агента

- Не подменять палитру/шрифты «дефолтным AI UI», не вводить светлую тему.
- Не использовать эмодзи как иконки — только `lucide-react`.
- Не добавлять сторонние скрипты, шрифты с CDN и `dangerouslySetInnerHTML` (CSP §8.7).
- Отклонения от токенов допускаются только с записью в этом файле и причиной (a11y, CSP).
