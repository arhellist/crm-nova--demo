> Эти акты **не являются доказательствами шагов**: они сняты при расследовании канона
> (см. `docs/AUDIT-witnessdone-1.31.0.md`), чтобы показать дефекты гейтов, и намеренно
> красные. В `OUTPUT/evidence/` их держать нельзя — `pre_release` и `sp status` читают
