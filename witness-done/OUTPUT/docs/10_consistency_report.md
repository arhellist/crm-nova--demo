## Рекомендации по фиксам (порядок)

1. BLOCKER'ов нет — можно стартовать D01.
2. Перед D01: `npm install`, `npm run lint` на каркасе (появится после D01), задать `.env` из

3. Перед первым релизом: собрать продуктовый smoke и закрыть пункт 6.

## Откат / что править

- Поля БД — источник правды `OUTPUT/specs/data-model.md`; при расхождении править промпт, не спеку.
- Контракт отчётов — источник правды `OUTPUT/specs/openapi.yaml`; типы фронтенда подстраиваются.
- Матрица переходов — источник правды `OUTPUT/specs/domain-rules.md`; D03 и D08 обязаны совпасть с ней.
