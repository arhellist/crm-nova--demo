## Сквозные проверки

| Контур | Где | Что доказывает |
|--------|-----|----------------|
| Unit / component | `src/**/*.test.ts(x)` | фразы A01–A12 |

| Replica | `infra/replica/*.test.mjs` | лаг, идемпотентность, запрет записи |

| Product smoke | `scripts/smoke/product-smoke.sh` | релизная приёмка |

## Правила

1. Строка плана не может называть тест, который фразу не объявляет.
2. Пропуск фразы = дыра; «напишем позже» — провал, а не отсрочка.
3. Статусы: `covered` (тест в PRODUCES задания), `ops` (внешний контур), `blocked` (запрещён к закрытию).
4. После выполнения D путь и статус уточняются по фактическим файлам.
