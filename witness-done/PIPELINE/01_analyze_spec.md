## Если NEEDS_HUMAN

1. Вопросы уже в `01_questions.md` (Business первым).
2. Попроси человека заполнить `INPUT/ANSWERS.md` по шаблону — **сначала § Business**.
3. В чате: `ANALYZE: NEEDS_HUMAN` + список критичных Q + «сохрани ANSWERS и напиши: ANSWERS готовы — продолжай».
4. При возобновлении: перечитай `ANSWERS.md`, обнови analysis, снизь статус до `done` если достаточно.
5. Если попыток ≥ 3 и ответов нет — прими defaults из `01_questions.md`, `defaults_applied: true` в MANIFEST, статус `done`, продолжай. Defaults по бизнесу помечай явно как гипотезы в analysis (высокий риск).

Критерии needs_human: нет ясности по **цели бизнеса**, **KPI успеха**, **кто платит/пользуется**, **что в v1**, **как логинимся**, **стек/БД**.  
Отсутствие SEO-решения при неясном GTM → вопрос Business, не «добавим SSR на всякий случай».
