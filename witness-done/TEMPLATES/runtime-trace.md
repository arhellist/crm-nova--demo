# Runtime trace — артефакт внешнего прогона

> Путь: `OUTPUT/evidence/D{{NN}}.trace.json`  
> Когда обязателен: `FIT_CHECKS.runtime_trace_required: yes` (для `L3` — по умолчанию `yes`, поле обязано быть названо явно; `no` — только осознанный отказ)  
> Канон: `catalogs/verification-tax.md` («Runtime trace»)

## Что это и чем не является

Трейс производится **снаружи** (браузер, staging, песочница агента) **или порождается фабрикой**
через `sp-verify --gate runtime`: в этом случае он несёт `produced_by` с `plan_hash` и номером фразы.
Внешний трейс по-прежнему принимается, если привязан к коммиту и к `PRODUCES`.

Свой автотрейс (`produced_by.tool == 'sp-verify'`) перезаписывается при повторном прогоне плана —
иначе после смены кода `pre_ci` навсегда видел бы «трейс от другого кода». Внешний трейс фабрика
не трогает никогда: его снимал человек.

Фабрика проверяет **форму, целостность и привязку**: артефакт относится к этому `D`, к этому
коммиту и к этому содержимому `PRODUCES`, записи непустые, файлы по `ref` существуют, а после
приёмки трейс не подменили.

Паритета с сервисами runtime-верификации здесь нет и не будет по одной причине: чтобы утверждать
«поведение соответствует фразе `Axx`», нужен оракул — машиночитаемое сопоставление фразы и сигнала,
плюс удостоверение, что сигнал снят доверенным CI на принятом коде. Фабрика даёт вторую половину
(привязка к коммиту и хешу кода) и не даёт первую: оракул — это тесты и смоук проекта, а удостоверение
— его CI. Обещать больше — продавать ложную гарантию.

## Схема

```json
{
  "d": "D03",
  "commit": "9f2c1ab",
  "code_hash": { "produces_digest": "…64 hex…" },
  "captured_at": "2026-10-28T12:00:00Z",
  "source": "playwright run против preview-сборки",
  "entries": [
    { "type": "api_response", "ref": "evidence/trace/charge-response.json" },
    { "type": "console_log", "ref": "evidence/trace/console.txt", "sha256": "…" },
    { "type": "screenshot", "ref": "evidence/trace/checkout.png", "sha256": "…" }
  ]
}
```

| Поле | Обязательно | Что значит |
|------|-------------|------------|
| `d` | да | Задание, к которому относится прогон. Несовпадение — провал |
| `commit` | да | Коммит, на котором снят трейс. `pre_ci` сверяет с `git HEAD`; другой код — провал |
| `code_hash.produces_digest` | да | 64 hex: дайджест `PRODUCES` исполненного кода. Расхождение — провал |
| `captured_at` | да | ISO-8601: когда снято. Без времени артефакт невозможно отличить от вчерашнего |
| `source` | да | Чем снято (инструмент, окружение). Пустая строка не принимается |
| `entries` | да | ≥1 запись |
| `entries[].type` | да | `api_response` \| `console_log` \| `screenshot` |
| `entries[].ref` | да | Путь к файлу. Ищется от корня проекта, от `OUTPUT`, от `OUTPUT/evidence` |
| `entries[].sha256` | нет | Если указан — сверяется с файлом; расхождение = провал |

## Куда класть файлы

В `OUTPUT/evidence/` (например `OUTPUT/evidence/trace/`): это служебный каталог, поэтому трейс-файлы
не попадают в `proof_debt` и не выглядят как незаявленный код.

## Цепочка целостности

1. `pre_ci` считает `sha256` файла трейса и кладёт в акт: `trace.hash`.
2. `evidence_hash` покрывает это поле — правка акта ломает печать.
3. `sp-verify --verify-evidence <акт>` пересчитывает хеш трейса: подмена после приёмки видна.
4. Сам по себе трейс не доказывает смысл: он доказывает, что прогон **был** и относился к этому коду,
   если `commit` и `code_hash` сошлись с принятым деревом.

## Пределы

- Внешний трейс можно подделать так же, как скриншот: фабрика ловит несоответствие формы, чужой
  коммит, чужой `code_hash` и подмену после приёмки, а не «правдивость» инструмента.
- Автотрейс слабее внешнего: он доказывает прогон команды на этом коде, но не независимость прогона.
  Удостоверение личности CI (OIDC/Sigstore или HMAC ключом из секрета) — не реализовано: без ключа
  подпись была бы самообманом.
- Хеш трейса не покрывает файлы, на которые он ссылается (если `sha256` у записи не указан).
  Для `api_response` указывайте `sha256` — иначе содержимое ответа можно переписать.
- `runtime_trace_required` не имеет смысла для `L1/L2`: там внешнего контура ещё нет.
