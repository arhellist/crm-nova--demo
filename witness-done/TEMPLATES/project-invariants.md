# Инварианты проекта — шаблон каталога

> Путь: `OUTPUT/docs/project-invariants.md`  
> Канон: `catalogs/invariants.md`. Правило живёт **здесь**, в заданиях — только ссылка `INV-###`.

## Зачем

Одно правило, повторённое в пяти заданиях, расходится на третьем. Каталог держит правило в одном
файле, а `pre_ci` проверяет не «умно», а детерминированно: по `module` из `FIT_CHECKS` и уровню задания.
Каждое выбранное правило обязано быть упомянуто в `## INVARIANTS` задания по ID.

## Формат

Каждый инвариант — заголовок `### INV-NNN — короткое имя` и таблица полей.

```markdown
### INV-001 — Деньги только в минорных единицах

| Поле | Значение |
|------|----------|
| Область | module:billing,checkout |
| Уровни | L2+ |
| Проверка | Суммы хранятся и считаются в целых минорных единицах; float в денежных путях запрещён |
| Waiver | — |
```

| Поле | Обязательно | Что значит |
|------|-------------|------------|
| `Область` | да | `all` или `module:<id>,<id>` — модули из `07_module_plan.md` |
| `Уровни` | да | `L1+`, `L2`, `L2+`, `L2/L3` — порог применения |
| `Проверка` | да | Что именно проверить. Формулировка без «качественно» и «разумно» |
| `Waiver` | нет | `причина: …; до: YYYY-MM-DD`. Просроченный waiver = провал гейта |

## Правила

- ID уникален и не переиспользуется после удаления правила.
- Область — только `all` или список модулей: «умное» угадывание запрещено, ложное применение хуже пропуска.
- Waiver обязателен с причиной **и** сроком: бессрочное исключение — это отмена правила.
- Задание ссылается на инвариант по ID в `## INVARIANTS`. Ссылка на несуществующий `INV-###` — провал.
- Если правило неприменимо ко всему заданию, в `FIT_CHECKS` пишется `invariants_skip: <причина>`;
  пустая причина не принимается.
- Каталог необязателен: нет файла — нет проверки (Lite-режим и малые проекты живут без него).

## Пример набора

```markdown
### INV-001 — Деньги только в минорных единицах

| Поле | Значение |
|------|----------|
| Область | module:billing |
| Уровни | L2+ |
| Проверка | Суммы в целых минорных единицах; float в денежных путях запрещён |
| Waiver | — |

### INV-002 — Внешний вызов всегда с таймаутом

| Поле | Значение |
|------|----------|
| Область | all |
| Уровни | L1+ |
| Проверка | У каждого сетевого вызова есть явный timeout и обработка ошибки |
| Waiver | причина: legacy-модуль payments; до: 2026-12-31 |
```
