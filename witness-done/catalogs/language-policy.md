# Политика языка документации

> Для всех артефактов `OUTPUT/**`, `AGENTS.md`, `.cursorrules` и ответов оркестратора.

## Правило

1. **Основной язык — русский**, если ТЗ на русском (по умолчанию для этой фабрики — русский).
2. Английский в прозе **недопустим** как основной язык разделов («Context», «Decision», «Role model» и т.п.).
3. Идентификаторы кода, пути файлов, имена HTTP-методов/полей API, имена пакетов — на английском **нормально** (это код, не документация).
4. Если нужен английский термин / аббревиатура — **сразу пояснение по-русски** в скобках или через тире при первом использовании в документе.

### Примеры

| Плохо | Хорошо |
|-------|--------|
| `## Context` | `## Контекст` |
| `Status: Accepted` | `Статус: принят` |
| `ports and adapters` | порты и адаптеры (ports/adapters — границы с внешними системами) |
| `NFR` без пояснения | NFR (нефункциональные требования: нагрузка, latency, доступность) |
| `hold/capture` без пояснения | hold (холдирование / блокировка средств) → capture (списание) |

## Обязательный мини-глоссарий (можно копировать в START_HERE / analysis)

| Термин | Пояснение |
|--------|-----------|
| ADR | Architectural Decision Record — запись архитектурного решения |
| API | Application Programming Interface — программный интерфейс |
| JWT | JSON Web Token — токен доступа в компактном формате |
| NFR | Non-Functional Requirements — нефункциональные требования |
| ORM | Object-Relational Mapping — слой объект↔таблицы БД |
| SLA / SLO | целевые уровни сервиса / цели надёжности |
| OLTP / OLAP | транзакционная БД / аналитическая БД |
| MQ | Message Queue — очередь сообщений |
| CI/CD | непрерывная интеграция и доставка |
| RBAC | разграничение доступа по ролям |
| PSP | Payment Service Provider — платёжный провайдер |
| webhook | входящий HTTP-колбэк от внешней системы |
| raw body | «сырое» тело запроса до JSON-парсера (нужно для проверки подписи) |

## Заголовки ADR (шаблон)

Использовать русский шаблон `TEMPLATES/adr.md`: Контекст / Решение / Альтернативы / Последствия.

## Проверка на шаге 10

В consistency report добавить пункт: документы на русском; английские аббревиатуры с пояснениями. Severity: MAJOR, если целые разделы на английском.
