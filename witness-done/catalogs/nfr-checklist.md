# NFR / Scale checklist (v1)

Отмечай применимость в `OUTPUT/docs/nfr.md`.

## Производительность

- [ ] Целевые p95 для ключевых эндпоинтов
- [ ] Стратегия пагинации (cursor/keyset vs offset)
- [ ] Индексы под все list/filter/sort
- [ ] Кэширование (что, TTL, инвалидация)
- [ ] Пул соединений БД настроен
- [ ] Таймауты на исходящие HTTP/DB

## Надёжность

- [ ] Идемпотентность мутаций
- [ ] Ретраи с backoff только на безопасных операциях
- [ ] Graceful degradation при падении зависимостей
- [ ] Миграции обратно совместимы (expand/contract)
- [ ] Health / readiness probes

## Наблюдаемость

- [ ] Структурные логи (requestId, userId без PII лишнего)
- [ ] Метрики (latency, error rate, queue lag)
- [ ] Трейсинг критичных путей

## Безопасность (NFR-часть)

- [ ] Rate limit на auth и публичные API
- [ ] Лимиты размера body / upload
- [ ] Секреты только в env / secret manager

## Capacity

- [ ] Оценка объёма данных на 12 месяцев
- [ ] План архивации / партиционирования (если нужно)
- [ ] Фоновые jobs отделены от request path
