# DEC-067 — На /team не показывать карточку текущего постановщика

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-2334-irina-volkova-postanovschik-ee-kartochka |
| Статус | принято |
| ADR | — |
| Заменяет | уточняет DEC-061 (кого рисуем в сетке) |

**Контекст.** Экран «Команда» — для постановщика, который смотрит менеджеров.
Карточка самого постановщика (Ирина Волкова в демо) не нужна; нужны только карточки
менеджеров команды.

**Решение.** `ManagerCards` отфильтровывает строку с `manager_id === profile.id`
текущей сессии. Вьюха `report_managers` без изменений (отчёт может содержать всех).

**Альтернативы.** Хардкод UUID сида — отвергнуто: ломается вне демо. Скрывать всех с
нулевым KPI — отвергнуто: пустые менеджеры всё равно члены команды.

**Чем подтверждено.** `ManagerCards.test.tsx` DEC-067; демо `/team` без карточки Ирины.
