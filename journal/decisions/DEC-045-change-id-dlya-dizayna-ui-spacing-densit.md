# DEC-045 — Change id `ui-spacing-density`: починить Tailwind-пайплайн и плотность UI

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-0006-horosho-voshel-teper-porabotay-s-dizayno |
| Статус | принято |
| ADR | — |
| Заменяет | — |

**Контекст.** После входа на локальный стенд UI «слипся»: навигация без зазоров, счётчики вкладок прилипли к подписям, нет отступов у полей и кнопок. В `dist/web` CSS ≈1 КБ и содержит сырые `@tailwind` директивы — PostCSS/Tailwind не подключены к Vite, утилиты не генерируются. Палитра и классы в исходниках уже по `design-notes.md`, но до браузера не доходят.

**Решение.** Change id для дизайна: `ui-spacing-density` (короткий id вместо slug intake). Объём: включить PostCSS+Tailwind в сборку SPA, подключить локальные шрифты по design-notes, при необходимости точечно усилить отступы контролов без смены палитры. Intake `20261106-0006`.

**Альтернативы.** Переписывать все экраны инлайн-стилями — отвергнуто: ломает токены Tailwind и design-notes. Менять палитру на «светлую/AI UI» — запрещено design-notes. Только косметика классов без PostCSS — отвергнуто: корень в отсутствии пайплайна.

**Чем подтверждено.** `dist/web/assets/*.css` содержит литералы `@tailwind` и не содержит `.flex`/`.gap-`; `postcss.config.*` отсутствует; зависимости `tailwindcss`/`postcss`/`autoprefixer` в `package.json` есть.
