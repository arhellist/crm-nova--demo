# DEC-024 — D11: список app_contracts в промпте обёрнут в обратные кавычки, из-за чего sp…

| Дата | 2026-11-04 |

| Статус | принято |

| Заменяет | — |

**Контекст.** `sp-verify` собирает `ops_checked` из `FIT_CHECKS → app_contracts` регулярным
выражением `METHOD /path`, где путь не может содержать запятую или пробел. В промпте D11 весь
список операций был обёрнут в одну пару обратных кавычек, поэтому парсер захватывал хвостовой
символ `` ` `` в путь (`GET /api/reports/objects\``) и не находил ни одной операции в `openapi.yaml`.
Это блокировало `app`-скоуп приёмки при фактически корректном контракте.

**Решение.** D11: список app_contracts в промпте обёрнут в обратные кавычки, из-за чего sp-verify парсит пути с хвостовым ` и не находит операции в openapi. Форматирование промпта исправляется на список без обёртки; код и контракт openapi не меняются.

**Альтернативы.** Править `checkAppContracts` в `SEED/sp-tools/sp-verify.mjs` (нормализовать
обратные кавычки) — отвергнуто: это правка инструмента фабрики ради одного промпта. Убрать
`app_contracts` — отвергнуто: ослабило бы проверку пяти операций уровня L2. Оставлено
исправление формата промпта: операции перечислены через запятую без обёртки.

**Чем подтверждено.** `witness-done/OUTPUT/prompts/D11_reports_api.md` (FIT_CHECKS
`app_contracts`), `witness-done/OUTPUT/specs/openapi.yaml` (пять операций),
`witness-done/OUTPUT/evidence/D11.json` → `app.ops_checked`, `app.missing: []`.
