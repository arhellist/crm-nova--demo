# DEC-033 — D01/D11: отчётный контур монтируется в единый backend-процесс

| Поле | Значение |
|------|----------|
| Дата | 2026-11-04 |
| Intake | — |
| Статус | принято |
| ADR | ADR-0002, ADR-0003 |
| Заменяет | — |

**Контекст.** `npm start` и `CMD` образа запускали `dist/server/index.js` — базовое
приложение D01 с одним `/health`. Отчётный контур D11 жил в отдельном Fastify внутри
`src/reporting/server.ts` и запускался только при прямом вызове этого файла. В результате
production-процесс отвечал 404 на `/api/reports/*`, `/health/replication` и `/metrics`:
продукт без отчётов. Обнаружено на staging-контуре при прогоне product-smoke (D14), а не
unit-тестами — каждый модуль тестировался отдельно и был зелёным.

**Решение.** Появилась `mountReportingSurface(app, options)`: охранные хуки (только чтение,
allowlist Origin, Bearer для `/api/*` и `/metrics`, метрики по ответам), маршруты отчётов,
`/health/replication` и `/metrics` регистрируются на том же экземпляре Fastify, что и D01.
`src/server/index.ts` читает конфигурацию контура чтения (`DATABASE_URL_REPLICA`, без
primary), поднимает пул реплики, монтирует контур и закрывает пул при завершении. `/health`
остаётся контрактом D01 (`version`, `commit`, `uptime_s`), поэтому `registerHealthRoutes`
разделён на «полный набор» (автономный процесс и тесты) и `registerReplicationAndMetricsRoutes`
(без повторной регистрации `/health`, которую Fastify запрещает).

**Альтернативы.** Запускать отчётный сервер вместо базового — терялся контракт `/health`
D01 и его rate limit. Держать два контейнера и маршрутизировать по путям — новый прокси и
двойной деплой при том же одном порту. Монтировать плагином с инкапсуляцией — сменило бы
404-контракт D01 на `E_NOT_FOUND`. Принято монтирование в тот же экземпляр.

**Чем подтверждено.** `src/reporting/server.test.ts` (A11.6): `/health` D01, 200 на
`/health/replication`, 401 без токена, 405 на POST, 200 с `source: replica`, 503 с
`retry-after` при недоступной реплике. Живой staging-контур: `/health` 200,
`/health/replication` → `streaming`, три отчёта 200, `/metrics` 200.
