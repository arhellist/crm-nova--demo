# DEC-059 — `/api/auth/me` возвращает профиль текущего пользователя, не первый из списка

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-2223-vse-loginy-i-paroli-vedut-na-postanovsch |
| Статус | принято |
| ADR | — |
| Заменяет | — |

**Контекст.** RLS на `profiles` разрешает читать все имена (нужно UI). `/api/auth/me`
делал `select` без фильтра и брал `rows[0]` — всегда Ирина Волкова (меньший UUID).

**Решение.** BFF определяет `user.id` через GoTrue `/auth/v1/user` по access cookie,
затем читает `profiles?id=eq.<uid>`. В ответ кладёт `email` из user.

**Альтернативы.** Сузить RLS до `id = auth.uid()` — отвергнуто: ломает имена в списках.
Сортировка массива по совпадению — хрупко.

**Чем подтверждено.** `routes.ts` /me; тест; smoke login executor ≠ manager на демо.
