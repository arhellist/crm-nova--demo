# DEC-062 — Счётчики в карточках менеджеров: только задачи с неархивных объектов

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-2311-v-kartochkah-menedzherov-ne-verno-pokazy |
| Статус | принято |
| ADR | — |
| Заменяет | уточняет DEC-061 (состав агрегата) |

**Контекст.** В `report_managers` учитывались все `tasks` с `archived_at is null` по
`author_id`, в том числе задачи объектов с `objects.archived_at is not null`. На демо у
Ирины это давало 8 задач (включая 2 с архивного «Гранит»), тогда как `report_objects` и
портфель активных объектов показывают 6. Комментарий к `objects.archived_at` требует
каскадного скрытия задач архивного объекта.

**Решение.** `report_managers` и политика `tasks_select` учитывают только задачи, у которых
объект активен (`objects.archived_at is null`). Физически строки задач не архивируются
(A03.8 без изменений).

**Альтернативы.** (1) Считать по `objects.created_by` вместо `author_id` — отвергнуто:
карточка про постановщика задач, не владельца объекта. (2) Каскадно писать
`tasks.archived_at` при архиве объекта — отвергнуто в этом изменении: меняет семантику
A03.8 и объём RPC.

**Чем подтверждено.** Миграция `0011_managers_exclude_archived_objects.sql`; pgTAP в
`supabase/tests/views_test.sql` (DEC-062); живые счётчики на демо после apply.
