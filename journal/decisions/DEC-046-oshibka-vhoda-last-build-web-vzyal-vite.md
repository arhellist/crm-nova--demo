# DEC-046 — Вход «неверный пароль»: бандл смотрел в cloud, seed — локальный

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-0015-nevernyy-login-ili-parol |
| Статус | принято |
| ADR | — |
| Заменяет | — |

**Контекст.** Пользователь получает «Неверный email или пароль» при seed-учётках. Прямой `POST` на локальный Auth с `nova-local-password` успешен; в `auth.users` три подтверждённых email. Бандл `dist/web` после `npm run build:web` содержал `https://hcuailgajbetllkmqrgq.supabase.co` из `.env.local`, а не `127.0.0.1:54321`.

**Решение.** Ошибка входа: last `build:web` взял `VITE_*` из `.env.local` (cloud), seed-учётки живут в локальном Auth `54321`. Пересобрать SPA с явным локальным URL/anon-ключом как в runtime-plan и перезапустить preview.

**Альтернативы.** Создавать тех же пользователей в cloud — отвергнуто для локального стенда (секреты/MFA не совпадают с seed). Править `.env.local` навсегда на local — риск: файл используется и для других режимов; явное окружение на сборке безопаснее.

**Чем подтверждено.** curl password grant на 54321 → access_token; бандл до фикса содержал cloud URL; после пересборки — `127.0.0.1:54321`, cloud отсутствует.
