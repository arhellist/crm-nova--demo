# DEC-060 — Постановщик создаёт менеджера из UI (узкое исключение INV-006/009)

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-2231-dobav-funkcional-dobavleniya-novogo-mene |
| Статус | принято |
| ADR | — |
| Заменяет | фрагмент §2.2 «нет управления пользователями» в части создания manager |

**Контекст.** Заказчик требует создание нового менеджера из учётки постановщика
с генерацией пароля. §2.2 и INV-009 запрещали UI-админку; INV-006 запрещал
`service_role` в backend. Без Admin API создать Auth-пользователя нельзя.

**Решение.** Постановщик создаёт только `manager` из UI `/team`; `SUPABASE_SERVICE_ROLE_KEY`
только на BFF для `POST /api/auth/managers`; пароль генерируется и отдаётся один раз
(без email); executor из UI не создаём.

**Альтернативы.** Оставить только регламент в Dashboard — отвергнуто заказчиком.
Gateway на service_role для всех данных — запрещено.

**Чем подтверждено.** Change-пакет `dobav-funkcional-dobavleniya-novogo-mene`;
маршрут `/api/auth/managers`; страница `/team`; тесты; smoke на демо.
