# DEC-064 — Запрос «смонтируй флешку» — системная операция на хосте, не изменение NOVA CR…

**Контекст.** Пользователь попросил смонтировать USB-флешку на хосте. Это не доработка продукта
NOVA CRM: нет PRODUCES, Dxx и change-пакета. Ограничение: RW-монтирование NTFS через udisks
не удалось (dirty/суперблок); доступен только `ro`.

**Решение.** Запрос «смонтируй флешку» — системная операция на хосте, не изменение NOVA CRM. Монтирование /dev/sda4 выполнено вне pipeline R02; change-пакет не создаём.

**Альтернативы.** Отвергнуто: открывать R02/change в CRM — запрос не про код продукта.
Отвергнуто: `sudo mount` без пароля в агентской сессии — нет интерактивного sudo.

**Чем подтверждено.** `findmnt` и `df`: `/dev/sda4` → `/media/alex/USB FLASH WIN7`, fstype `ntfs3`, options `ro`.
