# DEC-044 — Ручной вход на стенд: executor без MFA; manager — код из seed

| Заменяет | — |

**Контекст.** Нужна практическая инструкция входа в уже поднятое приложение, без путаницы вокруг Authenticator.

**Решение.** Для ручного входа на локальный стенд: проще `executor1@nova.local` / `nova-local-password` без MFA (в seed фактор только у менеджера). Менеджер — тот же пароль + одноразовый 6-значный код из seed-секрета, генерируемый локально командой; приложение Authenticator не обязательно.

**Альтернативы.** Требовать Authenticator для любого входа — лишнее трение на стенде. Отключать MFA менеджера — ломает приёмку A04.1/A14.1.

**Чем подтверждено.** `supabase/seed.sql`: MFA-фактор только у manager; `http://127.0.0.1:4173/login` отвечает 200.
