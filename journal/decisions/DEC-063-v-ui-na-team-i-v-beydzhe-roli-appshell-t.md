# DEC-063 — В UI только термин «менеджер», не «постановщик»

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-2318-kakrtochka-postanovschika-nenuzhna-tolko |
| Статус | принято |
| ADR | — |
| Заменяет | уточняет формулировки DEC-060/061 в UI |

**Контекст.** На `/team` блок KPI назывался «Постановщики», в шапке бейдж роли —
«Постановщик». Пользователь: карточка/лейбл постановщика не нужны — только менеджер.
В коде роль по-прежнему `manager`; меняется только пользовательский русский ярлык.

**Решение.** `AppShell`: `manager` → «Менеджер». `/team` и `ManagerCards`: заголовки и
пустые состояния — «Менеджеры» / «менеджеров». Доменные комментарии про постановщика в
статус-машине не трогаем.

**Альтернативы.** Убрать KPI-карточки целиком — отвергнуто: запрос про ярлык роли, не про
удаление статистики после DEC-061/062.

**Чем подтверждено.** `AppShell.test.tsx`, `ManagerCards.test.tsx`; демо-сборка.
