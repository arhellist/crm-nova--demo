# DEC-058 — Заморозка смены статуса после принятия

| Поле | Значение |
|------|----------|
| Дата | 2026-11-06 |
| Intake | 20261106-2221-posle-prinyatiya-zadachi-izmenenie-statu |
| Статус | принято |
| ADR | — |
| Заменяет | — |

**Контекст.** После «Принять» заказчик требует, чтобы статус больше нельзя было менять.
БД уже терминальна (`accepted: []`, `P0422`), но UI мог кратко оставлять кнопки до refetch
и не сообщал о фиксации.

**Решение.** UI при `accepted` не предлагает переходов; сразу после успешного RPC
использует новый статус из ответа; показывает «Статус зафиксирован»; инвалидирует
`my-tasks`. Правка title/description этим решением не затрагивается.

**Альтернативы.** Автоархив при принятии — отвергнуто (архив отдельная операция).

**Чем подтверждено.** StatusPanel/TaskRow; тесты DEC-058; change-пакет
`posle-prinyatiya-zadachi-izmenenie-statu`; domain-rules §1.
